# Project Statement

## Project Title
Algorithm Explorer & Complexity Analyzer

## Problem Statement

Students learning programming often understand the theory of algorithms but find it difficult to connect the algorithm, its execution, and its time and space complexity.

The purpose of this project is to develop a Python-based interactive tool that allows users to execute selected fundamental algorithms and understand their working and complexity.

## Scope

The project focuses on fundamental algorithms and problem-solving concepts covered in the – Problem Solving and Programming course.

The current version includes:

- Linear Search
- Selection Sort
- Recursive Factorial
- Recursive Fibonacci
- Tower of Hanoi
- Basic time and space complexity information
- Input validation
- Basic algorithm testing

The project does not use external libraries or advanced frameworks.

## Target Users
The primary users of this project are:

- Students learning Python
- Beginners learning algorithms
- Students studying problem-solving concepts
- Learners who want to understand basic algorithm complexity

## High-Level Features

1. Search Lab
   - Performs Linear Search on user-provided numbers.
   - Displays whether the target is found.
   - Displays the number of comparisons.

2. Sorting Lab
   - Performs Selection Sort.
   - Displays the original and sorted list.
   - Displays comparisons and swaps.

3. Recursion Lab
   - Calculates factorial recursively.
   - Calculates Fibonacci recursively.
   - Demonstrates Tower of Hanoi recursively.

4. Complexity Analyzer
   - Displays time and space complexity information.
   - Provides a short explanation of each algorithm.

5. Input Validation
   - Handles invalid integer input.
   - Handles invalid number lists.
   - Validates positive and non-negative values.

6. Testing
   - Includes basic tests for the implemented algorithms.
